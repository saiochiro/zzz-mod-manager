What's new in 2.14.23

- "SFW only" in Browse now opens complete. Brand new mods are checked before the list shows, so switching between SFW and NSFW no longer makes more safe mods pop in each time.
- ProxyLaunch remembers the mods it has already checked, even after you close it, so it doesn't start over every time you open it.
- When new mods finish being checked, Browse updates the cards in place instead of reloading the whole page.
- XXMI hasn't published Severian or Phoenix yet, so ProxyLaunch uses its own character data for them for now. A later update will switch them to XXMI's.

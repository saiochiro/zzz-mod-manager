What's new in 2.10.1

- Bigger character cursors. The agent cursors (fox ears, shark fins, wings, thrusters and the rest) are now larger and easier to see, and the previews in Themes are bigger too.
- Everyone gets the character cursors. If you had picked the plain Arrow or Blade shape before, it switches to Character once so you can see the new ones. You can change it back in Themes > Mouse cursor.
- Workshop tiles are all the same size now. Long mod names no longer stretch their picture; hover a name to see all of it.

What's new in 2.10.3

Fixes for installing updates.

- Updates no longer get stuck on "ProxyLaunch cannot be closed". The installer now closes every running copy of ProxyLaunch by itself, and updates from the app install quietly in the background and reopen ProxyLaunch when done.
- Only one ProxyLaunch runs at a time. Opening it again (or clicking a one-click install link in your browser) now brings up the window that's already open instead of starting a hidden extra copy, and the install link goes to that window.
